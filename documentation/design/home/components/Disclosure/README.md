A disclosure hides a group of rarely used settings on the same page.

- Markup: `<button class="disclosure" aria-expanded>` with a bold title and a muted line that lists what is inside; the opened content is ordinary cards below it.
- This replaces tabs nested inside a section ("Settings / Advanced settings"). The title names the group; the muted line lists its contents so nobody has to open it to find out.
- Closed by default. It remembers nothing between visits.
