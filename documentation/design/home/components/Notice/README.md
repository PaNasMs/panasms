A notice is a message that belongs to a place on the page and stays there until the situation changes.

- Markup: `<div class="notice">` with an icon and text; states `ok`, `warn`, `danger`. A bold first line says what happened, the next says what to do. Put buttons in `.actions`.
- Use a notice for a state of the page or object. Use a toast for the result of an action the person just took.
- An error says what went wrong and how to fix it. No apologies, no codes without words.
- Do not use a notice for "nothing here yet": that is the Empty state.
