The page header holds the page title, an optional one-line description and the actions that apply to the whole page.

- Markup: `<header class="page-head">` with `<h1>`, an optional muted line and `.actions`.
- Rule: nothing sits directly on the background. The user may set any wallpaper, so the title and page actions always live in this panel. The same holds for loose group headings: put them inside a card.
- One `h1` per page. Page actions use `button large`; the primary action, if there is one, comes last.
- A detail page (a user, a container) adds a `back-link` above the title that names the list it returns to.
- On a phone the header is a pill with the title on the left and round 44px buttons on the right.
