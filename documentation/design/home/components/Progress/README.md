A progress bar shows how far a running task is.

- Markup: `<div class="progress" role="progressbar" aria-valuenow>` with a `<span style="width:N%">`; add `indeterminate` when the share is unknown.
- Always pair it with the task name in words and the percentage or "Working…".
- The same bar is used in the taskbar chip, the Tasks menu, object cards and the phone progress row.
