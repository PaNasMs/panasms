A table shows many similar records for scanning and comparing: services, routes, log lines, OS updates.

- Markup: `<div class="table-wrap"><table class="table">`. Numbers use `class="num"` (right-aligned, tabular figures).
- The first column names the record in bold with an optional muted second line. State is a Tag.
- At most one visible button per row plus a "more" menu. Row height is at least 56px so buttons keep their 44px.
- Below 640px a table becomes a list of cards: the first column is the card title, the other cells are label-value rows. Never scroll a table sideways on a phone, except the log.
- Use cards, not a table, for objects that have their own actions and states (disks, interfaces, shares).
