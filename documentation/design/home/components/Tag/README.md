A tag names the type or the state of an object in one or two words.

- Markup: `<span class="tag">`; states `ok`, `warn`, `danger`; `info` for counters. A `dot` with the same state names marks state in dense lists and always stands next to the state in words.
- State is never colour alone: the tag carries the word, the dot is followed by the word.
- Neutral tags (`RAID5`, `SATA`, `Ethernet`) describe what a thing is; coloured tags describe how it is. One state tag per object.
- Use `warn` for something the owner should look at and `danger` only for failure or data at risk.
