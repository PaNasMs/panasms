The taskbar is the permanent shell: it opens the list of sections, holds the sections the person pinned, and shows running work.

- Computer (top): launcher "All sections", Desktop, pinned sections, then on the right running-task chips, removable devices (when present), Tasks, Notifications, Profile.
- Phone (bottom): launcher, Desktop, up to three pinned sections, Tasks with a counter. Notifications and Profile move to the page header. Running work shows as one progress row above the taskbar plus the counter on Tasks.
- The current section is the only `accent` fill on the screen. If the current section is not pinned, the launcher takes the accent.
- Pinned sets are separate for computer and phone. The launcher is called "Sections", never "Applications".
- Every item is 44px (52×48 on a phone) with an `aria-label` and a tooltip.
