Widgets are the tiles of the desktop grid: live figures and shortcuts to sections.

- Markup: `<section class="widget">` with `.w-title` and one main element: `.w-value` (a figure), `.ring` (a share, set `--p` to the percentage) or `.members`. A shortcut is `<a class="shortcut">` with a 36px icon and the section name, no plate under the icon.
- New: the Array widget — array name, level and capacity, a state tag, and one cell per member disk with its temperature. A warm or failed member changes its own cell. It does not exist in the current code and has to be added.
- One widget, one question. The whole widget links to the section that answers "why".
- The grid and the set of widgets are stored separately for computer and phone; the phone grid has two columns.
- Edit mode is entered from the page header ("Edit desktop"); widgets then show move and remove handles and the header offers Add widget, Wallpaper, Default layout, Save, Discard.
