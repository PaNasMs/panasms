# PaNasMs UI/UX guidelines

The canonical specification is now the [PaNasMs interface design standard](../docs/ui-design-guidelines.md).
Version 2.0 consolidates the general UI/UX and modal-dialog rules for core and modules.

Use that standard for new design, implementation and review. It includes navigation,
visual tokens, tabs, cards, tables, settings, selectors, dialogs, notifications,
background work, accessibility, localization and the acceptance checklists.
This page remains to preserve existing links; it contains no independent requirements.
